August Hour! (Sokoban)

Status: Active Development (Release 0.1.0)
Android (APK) / PC (EXE)

A 2D puzzle arcade mini game based on classic Sokoban mechanics built with GDevelop for both Android and PC. Players test their logic and spatial reasoning by strategically maneuvering blocks into target locations within compact environments.
